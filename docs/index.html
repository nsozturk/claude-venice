Overview

claude-venice is a free, open-source Claude Code CLI launcher for macOS that runs Claude Code against a local venice-bridge web subscription in an isolated profile with zero API cost.

  • Isolated profile: Keeps all state in ~/.claude-venice (CLAUDE_CONFIG_DIR) and unsets ANTHROPIC_API_KEY so your official Claude Code install is never modified.
  • Lean MCP mode: --lean disables MCP servers via --strict-mcp-config to keep tool prompts compact.
  • Preflight checks: Verifies venice-bridge (:18891), venice-adapters (:18892), active Venice login, and warns below 500 daily requests.

Quick Start

Make sure venice-bridge ≥ 0.2.5 (127.0.0.1:18891) and venice-adapters (127.0.0.1:18892) are running, then install the launcher:

git clone https://github.com/nsozturk/claude-venice.git
cd claude-venice
chmod +x claude-venice
ln -s "$PWD/claude-venice" ~/.local/bin/claude-venice
ln -s "$PWD/claude-venice" ~/.local/bin/cv   # optional 2-letter shortcut (bypassPermissions)

claude-venice --lean   # or: cv --lean

CLI Commands & Flags

CommandBehavior
claude-veniceStarts Claude Code in ~/.claude-venice with deepseek-v4-1-flash-uncensored and bypassPermissions.
claude-venice --leanDisables all MCP servers (--strict-mcp-config --mcp-config '{"mcpServers":{}}'). Works anywhere before --.
claude-venice -m <id>Switches Venice model (:web, :xsearch, :think, venice-auto, or local ollama/<model>).
claude-venice --resume <id>Resumes an older session while forcing bypassPermissions.
claude-venice --modelsLists all model IDs currently served by venice-bridge.
claude-venice --quotaPrints remaining daily Venice web quota and bridge cache stats.

Permissions & --resume

Warning: By default, claude-venice passes --dangerously-skip-permissions --permission-mode bypassPermissions so tools run without prompts — including on resumed sessions originally saved in default mode.

Set VENICE_CLAUDE_SKIP_PERMS=0 or pass an explicit --permission-mode default to restore interactive prompts.

VENICE_CLAUDE_SKIP_PERMS=0 claude-venice
claude-venice --permission-mode plan -p "Outline the refactor plan."

AI Agent Integration

When invoking claude-venice from another agent or script, always close stdin and use --lean -p:

claude-venice --lean -p "List failing tests and exit." </dev/null

Run offline unit tests (no network calls required):

python3 test_claude_venice.py

Alternatives / Compared With

  • Official Claude Code (Anthropic): Best-in-class reasoning and native tools, metered by API tokens or Claude subscription. claude-venice is a zero-API-cost companion for bulk exploration.
  • claude-code-local (ccl): Runs Claude Code offline against local Ollama/LM Studio models. claude-venice targets Venice's cloud web plan (with optional ollama/<model> pass-through).

FAQ

How do I run Claude Code with Venice AI on Mac without an API key?

Run venice-bridge + venice-adapters with your venice.ai browser cookie, then launch claude-venice. No Anthropic or Venice paid API key is needed.

Does claude-venice affect my official Claude Code login?

No. All config and history stay isolated in ~/.claude-venice.

When should I use --lean?

Whenever a repository defines many MCP servers in .mcp.json; disabling unused MCP tools keeps the tool prompt compact and improves reliability.
